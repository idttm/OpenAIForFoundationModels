# Support

Use GitHub Issues for reproducible package bugs and focused feature requests.
Include the package version, Xcode build, platform version, minimal
reproduction, and sanitized logs.

This project cannot provide support for OpenAI account access, billing, model
entitlements, service incidents, or Apple developer-program provisioning. Use
the corresponding vendor support channel for those issues.

For usage questions, first check [Getting started](Docs/GettingStarted.md), the
[API reference](Docs/APIReference.md), and existing issues. Report security
problems privately as described in [SECURITY.md](SECURITY.md).
