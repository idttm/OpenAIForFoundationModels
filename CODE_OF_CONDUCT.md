# Code of Conduct

## Our commitment

We want participation in this project to be safe, respectful, and productive
for everyone, regardless of background, identity, experience, or ability.

## Expected behavior

- Be considerate and assume good intent while discussing technical work.
- Give actionable feedback about code and ideas, not people.
- Respect privacy and never post another person’s credentials or user data.
- Accept maintainer decisions gracefully, including decisions to close or defer
  work that does not fit the project.

Harassment, threats, discriminatory language, sexualized conduct, deliberate
disruption, doxxing, and repeated personal attacks are not acceptable.

## Enforcement

Report conduct concerns privately using the repository host’s security advisory
feature. Maintainers may edit or remove content and temporarily or permanently
restrict participation when behavior threatens the community or project.
Reports will be handled as confidentially as practical.

This policy applies in repository discussions, issues, pull requests, and
project-managed community spaces.

This policy is informed by the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
version 2.1.
